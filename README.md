# Biologie bij Kamiel

Lesmateriaal biologie voor havo, vwo en onderbouw: uitlegfilms, tools en practica, begrippen, Binas-oefeningen, examentraining en de jaarplanner.

- `index.html` — homepage (hoofdstukken per niveau) en hoofdstukpagina's
- `films/<hoofdstuk>/` — uitlegfilms, elk één zelfstandig bestand (animatie + geluid)

De site wordt gepubliceerd met GitHub Pages vanaf de `main`-branch.
