# Door de mens gekozen — script v1 (alleen de regels die in v2 veranderden)

- Cold open: "zo klein als een knikker" → v2: "zo klein als een erwt". Dat is preciezer: de wilde tomaat *Solanum pimpinellifolium* is ± 1 cm.
- H2: "Een mopshond kan slecht ademen" → v2 met oorzaak: "met een heel korte neus". De vraag over rashonden is nieuw, voor de opbouw (één vraag per 60–90 s) en voor inteelt.
- H3: de bt-maïs had in v1 "een gif tegen insecten". v2: "een stof waar bepaalde rupsen niet tegen kunnen". Dat is genuanceerder; het werkt specifiek, niet voor alle insecten.
- H3: de zin "In Europa zijn daar strenge regels voor" is erbij gekomen, zonder een oordeel te geven (Part B type I: nooit een persoonlijke keuze voorschrijven).
