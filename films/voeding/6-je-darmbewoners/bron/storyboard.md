# Storyboard · Voeding 6 · Je darmbewoners

| Segment | Look | Beeld |
|---|---|---|
| s01 | Macro | Man van zeventig in een ziekenhuisbed; tijdlijn met kuur → diarree → kuur → diarree → donor → beter; slangetje naar de darm; vraagteken |
| q02 | Vraagkaart | Waarom werkt de poeptransplantatie? a medicijn in de ontlasting · b donorbacteriën nemen plek en voedsel in · c spoelt de ziekmakers weg |
| s03 | Titel | Micro · bacteriën aan de darmwand |
| s04 | Schema | Dunne darm → dikke darm als buis (≈ 1,5 m); wat overblijft: water, vezels, eiwitresten, slijm; water terug; "geen eigen enzymen"; de darm vult zich met bacteriën; 40 000 000 000 000 |
| s05 | Micro | Darmwand onder, darminhoud vol bacteriën; label microbioom; "iets wat je kwijt wilt?" → "je wordt er niet ziek van"; stippellijn: buiten je weefsel; stoof met open petrischaaltje; vraagteken |
| q06 | Vraagkaart | Er groeit bijna niets in het open schaaltje. Hoe komt dat? a te weinig voedsel · b te veel zuurstof · c te zuur |
| s07 | Micro | Schaaltje met lucht = zuurstof; zuurstofgloed vanaf de wand (O₂ uit het bloed), wandcellen en bacteriën bij de wand gebruiken het; "hier bijna geen zuurstof"; tag nabootsen: geen zuurstof · 37 °C · licht zuur tot neutraal |
| s08 | Schema | Mens links, bacteriën rechts; pijlen "warme plek · eten" en "brandstof · bescherming"; label mutualisme; één koraalrode bacterie "een paar kunnen gevaarlijk worden"; het bewijsbord verschijnt met de eerste stip bij vastgesteld |
| s09 | Micro | Vezel (groene keten); jouw enzymen doorgestreept; bacterie-enzymen knippen → losse suikers; cellulose blijft heel; zachtere vezels gaan wel; bord bonen met gasbellen; vraagteken |
| q10 | Vraagkaart | Hoe halen de bacteriën energie uit de suikers van de bonen? a verbranding met zuurstof · b gisting, zonder zuurstof · c vertering met alvleesklier-enzymen |
| s11 | Micro | Bacterie neemt suikers op → energie; label anaerobe dissimilatie · gisting; gasbellen CO₂ en H₂ stijgen; archaea → CH₄ bij 1 op de 3; tags ½–1½ liter, geur, bord bonen |
| s12 | Micro | Korte vetzuren uit de bacterie; vergelijking vetzuur (film 3) tegenover kort vetzuur; opname door de wand → brandstof; 5–10 % van je energie; vitamine K; paard: kleine dikke darm rechtsboven met tags 'reusachtige dikke darm vol bacteriën' → 'cellulose wél grotendeels afgebroken → leeft op gras' → 'bij ons: klein, maar nuttig aandeel'; klein bord rechtsboven: vastgesteld |
| s13 | Micro | Melksuiker onverteerd; bacterie vergist → gas en krampen; suiker houdt water vast; pijlen naar de wand doorgestreept: water gaat niet terug; tag diarree = meer water in de darm dan er wordt teruggenomen |
| s14 | Micro (vwo) | Korteketenvetzuren: azijnzuur, propionzuur, boterzuur; boterzuur → wandcel; kiemvrije muis tegenover gewone muis, darmwand dunner; obligaat anaeroob; "daarom mislukte het open schaaltje" |
| s15 | Schema | Zwerm bacteriën met pil: "doodt ook een groot deel van je darmbacteriën"; populatiegrafiek: drie soorten storten in tijdens de kuur en herstellen deels; Clostridioides difficile verschijnt; tags 1 op de 10, ziekenhuis |
| q16 | Vraagkaart | Waardoor groeit juist de ziekmaker na de kuur uit? a leeft van dode bacteriën · b geen concurrentie meer · c resistent geworden |
| s17 | Schema + Micro | Grafiek met de ziekmaker die uitgroeit; tags stap 1 en 2; paneel spore (pil komt er niet doorheen, ontwaakt en deelt); resistentie = overleven; wand met gifstoffen → ontstoken wand lekt vocht → diarree, koorts; nieuwe kuur: sporen blijven, bewoners nog niet terug |
| s18 | Schema | Gezonde donor → ontlasting vol bacteriën → verdund, gezeefd → slangetje voorbij de maag naar de man; label poeptransplantatie; Amsterdams onderzoek: loting, twee groepen van tien poppetjes, 8 tegenover 3 genezen; vroegtijdig gestopt; bewijsbord: vastgesteld / waarom: waarschijnlijk |
| s19 | Schema | Klein bord; probioticum-flesje; 100 stippen, 70 groen; "bewezen, zegt de reclame"; vraagteken |
| q20 | Vraagkaart | Wat ontbreekt er? a groep met dezelfde kuur zonder drankje · b veel grotere groep · c groep die het drankje blijft nemen |
| s21 | Schema | Tweede groep van 100 zonder drankje: misschien óók 70; het lot bepaalt; "soms iets, soms niets" → waarschijnlijk; het bewijsbord met definities per vak en alle stippen; overgewicht als hypothese |
| s22 | Schema (vwo) | Darm en hersenen; label darm-hersen-as (hypothese); stoffen via bloed en zenuwen; kiemvrije muis tegenover muis met darmbacteriën: ander gedrag; depressie ↔ ander microbioom; vraagteken |
| q23 | Vraagkaart (vwo) | Wat mag je concluderen? a darmbacteriën veroorzaken depressie · b depressie verandert je darmbacteriën · c alleen dat de twee samengaan |
| s24 | Schema (vwo) | "een verband is geen oorzaak"; pijl a (microbioom → stemming) en pijl b (stemming → microbioom) met het broodje als omweg; beslissen: microbioom veranderen + stemming meten + controlegroep; hypothese; zonder controlegroep geen plek op het bord |
| s25 | Macro + Micro | De man wordt beter; inzet "zijn dikke darm" verandert van koraal (ziekmaker) naar teal/groen; tags plek en voedsel ingenomen, antwoord b, vastgesteld / waarschijnlijk |
| s26 | Schema | Dikke darm met bacteriën; vezels → gas + korte vetzuren; water terug; ontlasting wordt bruin, ⅓ van de vaste stof is bacteriën; de lijnenkaart van film 2 met het broodje dat de hele reis aflegt: geknipt, opgenomen, langs de lever, opgegeten door je darmbewoners |
