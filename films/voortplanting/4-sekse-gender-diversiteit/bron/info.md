## Hoe je de film aanpast
Werkmap opzetten: kopieer `bron/` naar `hw/vp4` (scenes.js uit `src/`, `words/` = `stem/woordtijden/`, `film/4-sekse-gender-diversiteit/audio/` = `../audio/`), engine = `src/*.js` + `bouw/*`, `uitspraak_film.json` in de werkmap. Dan:
- tekst: `script_v2.md` aanpassen → `python3 engine/make_segments.py vp4 script_v2.md` → alleen gewijzigde alinea's opnieuw inspreken (Roos, eleven_v4, één take, prompt = `voice`-veld) → **pas als die TTS klaar is** Scribe (connect_from = de TTS-node; anders draait de flow de TTS opnieuw) → `engine/align.py` → `python3 film.py` → `engine/build_data.py vp4` → `engine/build.py vp4` → `bash pack.sh vp4 4-sekse-gender-diversiteit voortplanting`.
- beeld: alleen `scenes.js` → `engine/build.py vp4` → pack. Let op deelwoord-matches bij cues: 'Y' vindt 'embryo', 'aan' vindt 'aanleg', 'W' vindt 'vrouwtje', 'sekse' vindt 'intersekse' (controle: `python3 cuecheck.py vp4`).
