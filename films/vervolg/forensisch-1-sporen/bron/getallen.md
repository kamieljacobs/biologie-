Elke bewering met een getal, of met altijd/nooit/alleen/geen, met bron. "Niet gecontroleerd" = geen bron gevonden die ik kon openen; dan staat het niet als feit in het script.

## Luminol
| Bewering in het script | Bron | Opmerking |
|---|---|---|
| Luminol + waterstofperoxide in basische oplossing; het ijzer in hemoglobine (heem) versnelt de reactie; er komt blauw licht vrij (chemiluminescentie), ongeveer 425 nm | https://en.wikipedia.org/wiki/Luminol | nm wordt niet uitgesproken |
| (niet meer in script v2) Het licht duurt ongeveer dertig seconden per keer spuiten; je hebt het donker nodig en fotografeert met lange sluitertijd | https://en.wikipedia.org/wiki/Luminol ; https://www.bluestar-forensic.com/?p=10410 | |
| Hoe fel het licht is, zegt niet hoeveel bloed er is | https://en.wikipedia.org/wiki/Luminol | |
| Vals-positief: bleekmiddel (chloor), koper- en ijzerverbindingen, mierikswortel, poep, sigarettenrook | https://en.wikipedia.org/wiki/Luminol ; https://www.bluestar-forensic.com/?p=10410 | In Tobe e.a. 2007 reageerde luminol níet op mierikswortel en (na drogen) níet op 5% bleek; wél op kopersulfaat en ijzersulfaat. Script noemt daarom "chloor of koper" als *kan* ook licht geven, niet als altijd |
| Luminol reageert ook op bloed dat ongeveer tienduizend keer verdund is | Tobe, Watson & Nic Daéid, J Forensic Sci 52(1) 2007, tabel 2: https://www.bluestar-forensic.com/wp-content/uploads/2020/09/jfs_v52-1_eval_6_presumptive_tests.pdf | 1:100 000 nog zwak; 1:1 000 000 niet meer. Andere bronnen noemen veel hogere gevoeligheid; ik houd het bij tienduizend ("ook nog") |
| DNA is na luminol vaak nog te onderzoeken, maar luminol kan andere testen op hetzelfde spoor hinderen | https://en.wikipedia.org/wiki/Luminol | Daarom: zichtbare vlek eerst bemonsteren, dan pas spuiten |
| Luminol reageert op bloed van elk dier ("niet alleen menselijk bloed") | https://www.bluestar-forensic.com/?p=10410 | |

## Kleurtest (Kastle-Meyer, fenolftaleïne)
| Bewering | Bron | Opmerking |
|---|---|---|
| Vochtig wattenstaafje, eerst de kleurloze testvloeistof (gereduceerd fenolftaleïne, fenolftaline), een paar seconden wachten, dán waterstofperoxide (3%); meteen roze = positief | https://sciencenotes.org/kastle-meyer-test-for-blood/ ; https://en.wikipedia.org/wiki/Kastle%E2%80%93Meyer_test | |
| Waarom die volgorde: wordt het al roze vóór de peroxide, dan zit er een andere oxidator (koper- of nikkelzout); test telt niet | idem; Tobe 2007 (kleur vóór H₂O₂ bij metaalzouten) | |
| Roze na meer dan ongeveer dertig seconden telt niet: de vloeistof verkleurt in de lucht vanzelf | https://sciencenotes.org/kastle-meyer-test-for-blood/ | |
| Hemoglobine werkt als een peroxidase (peroxidase-achtige activiteit van heem) | https://en.wikipedia.org/wiki/Kastle%E2%80%93Meyer_test ; https://www.ncbi.nlm.nih.gov/pmc/articles/PMC9271945/ | "pseudoperoxidase"; script: "werkt als een enzym", met "vereenvoudigd" |
| Vals-positief: plantenperoxidasen (mierikswortel, aardappel, broccoli, bloemkool) | sciencenotes; Tobe 2007 (aardappel, mierikswortel, bruine bonen: vertraagd roze) | |
| De test maakt geen onderscheid tussen mens en dier | https://en.wikipedia.org/wiki/Kastle%E2%80%93Meyer_test | |
| Kleurtest positief bij tienduizend keer verdund bloed (25 van 25) | Tobe 2007 tabel 2 | |
| Kleurtest negatief = vrijwel geen bloed; positief = alleen "kan bloed zijn" (voorproef) | sciencenotes; Wikipedia KM | |
| Het NFI noemt in zijn vakbijlage de **tetrabasetest** (geen Kastle-Meyer) als kleurtest, naast een immunologische test en luminol | koppen in https://www.forensischinstituut.nl/sites/default/files/bijlage/2025-12/Vakbijlage-Onderzoek-naar-biologische-sporen-v2-jan25.pdf | Inhoud niet te openen (alleen koppen).
