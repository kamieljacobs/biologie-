# Examenbronnen (pdf's van het CvTE)

De originele examens die Kamiel aanlevert, per examen een map `<niveau>-<jaar>-<tijdvak>/` met de oorspronkelijke bestandsnamen van examenblad.nl:

- `…-o.pdf` = opgaven (het examen zelf)
- `…-c.pdf` = correctievoorschrift
- `…-c-a1.pdf` = aanvulling op het correctievoorschrift (als die er is)
- eventueel `…-b.pdf` (bijlage) of `…-u.pdf` (uitwerkbijlage)

Gebruikt voor de oefenexamens (`tools/OEFENEXAMEN_PROMPT.md`: foto's met `pdfimages`, figuren natekenen, nakijken) en de Examenatlas (`scripts/examenknip/`). Nieuwe pdf's van Kamiel komen hier ook, met dezelfde naamgeving. De omzettingstabel staat niet als pdf maar als webpagina op examenblad.nl (zie de prompt).
